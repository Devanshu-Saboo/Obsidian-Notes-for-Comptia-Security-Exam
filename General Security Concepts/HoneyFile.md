Honey Files are specific files that contain fake information which would look real to an attacker. This could include fake client details, email addresses, source code etc.

Another way to bait and trap a threat actor is by giving the honey file a name such as "passwords", which could be further encrypted with an easily broken encryption technique to make a threat actor believe it is real information.

Since there is no reason for any real employee to open such a file, the file can be set up so that an alert is triggered as soon as anyone opens or copies it. ==🟢ex. A file called "passwords.xlsx" sitting on a file server that sends an alert to the security team when it is opened==
