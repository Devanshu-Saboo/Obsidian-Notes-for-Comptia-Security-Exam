A security control is simply anything we put in place to reduce the risk of an attacker getting to our data or systems. Instead of looking at every control as a random one-off tool, we group them so that we can plan our security properly and make sure we are not missing a whole area.

There are 4 major categories of Security Controls, and each one is defined by *what is used to implement it*:
1. [[Technical Controls]]: implemented using systems ==🟢ex. Firewalls, Anti-Virus==
2. [[Managerial Controls]]: implemented using policies and planning ==🟢ex. Security Policies, Risk Assessments==
3. [[Operational Controls]]: implemented using people ==🟢ex. Security Guards, Awareness Training==
4. [[Physical Controls]]: implemented using physical barriers ==🟢ex. Locks, Badge readers==

A good way for me to remember this is by asking one question, "what is actually doing the job here?". If it is a system, it is technical. If it is a written rule, it is managerial. If it is a person, it is operational and if it is something I can touch like a door or a lock, it is physical.

For the exam, you will usually be given a control and asked which category it falls under, so this question is the quickest way to get to the answer. These categories are different from the 6 control *types* we will look at in [[Security Control Types]], which describe what the control does instead of what it is made of.
