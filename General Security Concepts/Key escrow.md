This is the same as the previously mentioned asymmetric encryption mentioned earlier only in this case, your private keys are instead managed and owned by a 3rd party organization. This would be helpful in organizations where even if a person were to leave the company, their encrypted data would still be accessible to the organization. 

This may also be used when 2 different organizations are working on a common task, where each organization would have a copy of the private key to be able to easily access data that is required.
