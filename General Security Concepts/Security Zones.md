In Security Zones, security will be more than a one-to-one relationship between the user and the organization network. 

For example an organization can setup multiple zones inside the organization network with some zones being untrusted such as trying to connect from the internet and certain zones being trusted such as when trying to connect from the internal company network and if the physical location of the device is inside the organization premises.

Thus the policies would be setup as such devices on an untrusted security zone would not be able to access data that is on a trusted security zone as well as only trusted security zone devices may access internal zone traffic.

Trusted security zones can also be further split into more smaller security zones via the addition of trunk switches and different VPN connections.
