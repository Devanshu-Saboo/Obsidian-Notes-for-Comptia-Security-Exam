Encryption technologies are the tools that give us secure key storage, cryptographic functions and data privacy. In [[Cryptographic Keys]] we saw that the key is the thing that actually protects the data, so if the key is stored badly the best algorithm in the world will not save us. These are the tools that are used to look after those keys. There are 4 of them I need to know for the exam:
1. ==🟠TPM==
2. ==🟠HSM==
3. ==🟠Key Management System==
4. ==🟠Secure Enclave==

### TPM (Trusted Platform Module)
A TPM is a chip, or a subsystem, that is built into the motherboard of a modern computer. It handles cryptographic functions in hardware and has persistent memory, so unique keys can be created and stored securely on that specific machine. ==🟢ex. BitLocker full disk encryption, which uses the TPM to generate and hold the keys so the drive can only be unlocked on that machine==

The keys generated by the TPM can also be password protected, which makes it resistant to brute force and dictionary attacks. It is meant for a *single device*, which is the main thing that separates it from the next one.

### HSM (Hardware Security Module)
An HSM is basically a TPM for a much bigger environment. It is usually a clustered system, with redundancy, that is used to securely store the encryption keys of hundreds or thousands of devices. ==🟢ex. The keys for a whole farm of web servers, kept in one secure place==

It also works as a ==🟠cryptographic accelerator==, which means that it takes the heavy encryption and decryption work away from the CPUs of other devices, which is helpful when you are encrypting in real time at a large scale.

### Key Management System
When there are lots of devices and applications, each with their own keys, we cannot manage them by hand. A key management system (KMS) is a centralized way to manage all the different types of keys from a single console. It can run on premises or it can be cloud based, and it lets us:
1. Keep track of where each key is and who is using it
2. Set up rules for how keys are used
3. ==🟠Rotate keys== automatically, which means regularly replacing the old key with a new one so that a stolen key does not stay useful forever

### Secure Enclave
A secure enclave is a dedicated security processor which is built into devices such as phones and laptops, separate from the main CPU. It gives us data privacy even if the device ends up in the wrong hands, and it provides:
1. Real-time memory encryption (which helps with the data in use problem from [[Encrypting Data]])
2. A hardware based random number generator
3. Built-in root cryptographic keys that cannot be changed, which act as a ==🟠root of trust== for all of the other cryptography on the device

> [!joke] TPM guards one house, HSM guards the whole neighbourhood and KMS is the person with the clipboard keeping track of all the keys.
