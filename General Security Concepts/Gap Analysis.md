In simple terms, it is the difference between the current state of the security system versus the state of the ideal security system which you want to implement. This can be a very long process taking weeks to months.

An easy way to streamline the process is to use a framework that can you begin implementing to reach the ideal security system, ==🟢ex. NIST (National Institute of Standards and Technology), ISO (International Standards Organization) 27001, HIPPA etc.==

If required you may also make your own framework within the organization to follow and implement a baseline security framework.

Steps involved in Gap Analysis:
1. Choosing the Framework
2. Evaluate People and Processes
3. Compare and Contrast existing and ideal systems
4. Analysis and Report
