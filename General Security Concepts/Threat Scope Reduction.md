The scope of the company in simple terms is all the possible pathways an attacker or unauthenticated user can use to attempt to gain access to the organization's internal network. This is also commonly called the attack surface, so the smaller the scope the fewer places an attacker has to try.

The reduction of this scope could include ==🟢allowing a user to only connect to the system via a VPN connection, checking the physical location of the device and limiting access to devices inside the organization's premises.==

Some other ways to reduce it are turning off services and ports that are not being used and limiting which systems a particular user can even see on the network. The less there is to attack, the less there is to defend.

This pairs with [[Adaptive Identity]]: one collects information about the user and device, and this reduces the number of ways they can get in to begin with.
