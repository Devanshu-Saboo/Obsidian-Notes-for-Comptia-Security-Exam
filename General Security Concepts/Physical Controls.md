Physical controls are controls that limit physical access to the organization. These are real world objects that you can see and touch, which stop a person from simply walking up to a system. ==🟢ex. Locks, Badge readers==

These are the controls that prevent a malicious attacker from gaining "physical" access to any of the systems inside the organization. This matters a lot because if an attacker can physically reach a server, a lot of our technical controls can be bypassed. Some more examples are:
1. ==🟠Fences and Barricades==: Keep people and vehicles away from the building
2. ==🟠Door locks and Badge readers==: Only let in people who have the right key or access badge
3. ==🟠Access control vestibules==: A set of doors where the second door will not open until the first one has closed
4. ==🟠CCTV and Lighting==: Make it easier to spot and identify anyone who should not be there

I have gone into these in a lot more detail, along with the different types of sensors, in [[Physical Security]] so make sure to go through it for the exam.

Just like [[Operational Controls]], this can be confusing at first. If the control relies on a *person* to do it, like a guard, it is operational. If it is an *object* that does the job on its own, like a lock or a badge reader, it is physical.
