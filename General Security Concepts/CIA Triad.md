The CIA Triad is made up of 3 points of a triangle, each relating to a different security objective to maintain. Pretty much everything we do in security can be traced back to protecting at least one of these 3 objectives, namely:
1. [[Confidentiality]]: Only the right people can see the data
2. [[Integrity]]: The data has not been changed by anyone it should not have been
3. [[Availability]]: The data is there when the right people need it

Each of these can be attacked separately. ==🟢ex. A data leak breaks confidentiality, someone secretly changing the numbers in a financial report breaks integrity and a ransomware or DoS attack breaks availability.==

An important thing to remember is that these objectives often pull against each other. If we lock data down as much as possible for confidentiality, it becomes harder for authorized users to reach it which hurts availability. A big part of security is balancing the 3 for what the organization actually needs.

Alongside this triad there is also [[Non-Repudiation]], which is closely related to integrity and which we will cover after the triad.
