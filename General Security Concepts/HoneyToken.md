A honey token is information that can be traced back. In simpler terms this means fake API keys, a list of fake email address, fake passwords etc. 

When searching for information leakage about the organization, if you see any of these fake data points pop up anywhere other than the honeypot, you can trace it back to the honeypot that it was leaked from and investigate the specific system for threat actors that may have gotten access to it.
