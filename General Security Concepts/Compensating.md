Compensating control types are implemented when you wish to use other means to control a security event until you can put together a plan to resolve it. These are usually temporary measures, used when the main control is not possible or is not enough.

For example, a security event has occurred but you don't have the means to reverse the damage. If an attacker targets the power supply to the main site, a backup generator would be compensating for the lack of power in the organization. ==🟢ex. Backup generator, A hot site to run from while the main site is down, Putting an unpatchable system behind a strict firewall==

Another common real life case is a legacy application that can no longer be patched (see [[Technical Change Management (Surplus topics)]]). Since we cannot fix the application itself, we compensate for it by isolating it from the rest of the network so that the risk is reduced.

The difference with [[Corrective]] is that corrective *fixes* the problem while compensating just *covers* for it in the meantime.
