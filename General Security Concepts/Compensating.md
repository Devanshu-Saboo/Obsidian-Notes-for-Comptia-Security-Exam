Compensating control types are implemented when you wish to use other means to control said security event until you can put together a plan to resolve it. 

For example it is a security event that has occurred but you don't have the means to be able to reverse the damage. For example if an attacker targets the power supply to the main site, a backup generator would be compensating for the lack of power in the organization.
